## Demo vs production

Demo agents look clever. Production agents need budgets, tool allowlists, and a story for when the model invents a step.

## Keep the loop small

Keep the loop small: plan, act, check. Log every tool call. Prefer deterministic validators over another model pass when the output shape is known.
